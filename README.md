# Fonecta Caller Growth Audit

**Live → https://eddieatadapty.github.io/fonecta-flow-rebuild/**

Five ideas to turn more Fonecta Caller users into subscribers, each built into a clickable version of Fonecta Caller's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Show an identified call before the price | +10–20% CR to purchase |
| 02 | Keep each ad’s promise on the first screen | +5–10% CR to purchase |
| 03 | Let one answer name the paywall | +5–10% CR to purchase |
| 04 | Show the 14 free days, and 3,75 € a month | +5–15% ARPU |
| 05 | Ask for the phone number last, with a way round the code | +3–8% CR to purchase |

Every price, rating and feature comes from Fonecta Caller's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for Fonecta Caller. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
