Day 1

Pass the campaign into Adapty

After a one-time SDK setup, the YouTube or Meta campaign each install came from arrives as a user attribute and picks the flow at first open. No app release.

Week 1

One flow per promise

Caller ID, the free weeks and “important call or scam” each get their own first screens; people who search your name keep today’s start.

Week 2

Judge each ad on what it earns

Each flow against today’s, measured on trials, paid subscriptions and what each install from that ad earns, so spend follows the promise that pays.

All three phones run the whole flow with the five ideas. Both Meta ads link to fonecta.fi today, so these phones show the app flow those ads could open instead. Fonecta Caller runs no Apple Ads that we can see. This layer carries no range: only a test per ad can give one.
